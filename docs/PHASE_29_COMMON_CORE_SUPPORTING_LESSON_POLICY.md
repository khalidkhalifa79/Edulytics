# Phase 29 — Common Core Supporting Lesson Policy

## Accepted classification

The accepted Common Core pedagogical graph contains:

- 1,560 in-scope pedagogical lessons in the deployed product runtime graph;
- 1,466 lessons with at least one exact accepted formal
  Standard / Learning Outcome mapping;
- 94 source-valid pedagogical lessons with no formal OutcomeCode.

The 94 zero-formal lessons are not database drift.

They are the exact lessons preserved by the accepted source blueprints where
the pedagogical source does not supply an appropriate numbered Addressing
standard for that lesson.

Edulytics MUST NOT fabricate an official Standard / Outcome mapping merely
to make those lessons independently publishable.

## Kindergarten product-scope exclusion

Common Core Kindergarten remains preserved in the verified official
curriculum framework because it is part of the authoritative source.

It is outside the Edulytics product lesson scope.

Therefore:

- no Kindergarten pedagogical product lessons are seeded;
- no Kindergarten canonical lesson-content bodies are created;
- Kindergarten is not exposed as a selectable student curriculum level;
- Kindergarten is excluded from Phase 29 content denominators;
- official Kindergarten Standards are not deleted or rewritten.

The product pedagogical rollout begins at **Grade 1**.

## Canonical-content rule

### Standalone canonical lesson target

A pedagogical lesson is a standalone canonical lesson-content target when it
has at least one exact accepted official Standard / Learning Outcome mapping.

For the current Common Core graph:

- standalone canonical targets: **1,466**.

These lessons must receive the Phase 29 canonical body:

- Explanation;
- Key Concepts / Rules;
- Worked Examples;
- Step-by-Step Solutions;
- Common Mistakes;
- Quick Summary;
- canonical English academic content;
- provenance;
- mathematical verification;
- curriculum review;
- Published status.

### Source-valid supporting pedagogical lesson

A lesson with no formal official OutcomeCode may be retained as a supporting
pedagogical lesson only when its zero-formal state is proven by the accepted
source blueprint.

For the current Common Core graph:

- supporting pedagogical lessons: **94**.

Supporting lessons:

- remain preserved in the pedagogical sequence and source provenance;
- do not receive fabricated official mappings;
- receive complete canonical English bodies;
- are counted in overall Content Ready coverage;
- appear in staff and enrolled-student navigation and open in both readers;
- are clearly labelled Supporting and expose no fabricated official outcome.

## Production Ready denominator

For Common Core Phase 29 content rollout:

- in-scope pedagogical product graph = 1,560;
- standalone canonical-content target = 1,466;
- supporting-only source lessons = 94.

Common Core content closure therefore requires:

**1,560 / 1,560 lessons Content Ready**

plus:

**94 / 94 supporting-only classifications preserved and unchanged**

with:

- zero fabricated official mappings;
- zero unexplained zero-formal lessons;
- zero missing required body sections among all 1,560 lessons.

The separate alignment classification is 1,466 Officially aligned and 94
Supporting. It must not replace 1,560 as the readiness denominator.

Common Core canonical-content generation.
