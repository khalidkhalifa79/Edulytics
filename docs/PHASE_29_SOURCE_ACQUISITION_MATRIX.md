## Global rule

The operational Edulytics target school year is 2026-2027.

Official Standards / Learning Outcomes remain the final academic authority.

Pedagogical source priority remains:

1. school-adopted textbook;
2. current official/ministry textbook or material;
3. evidence-backed widely-used publisher textbook;
4. official framework only when no suitable textbook can be resolved.

`ResearchRequired` is a real blocking state and must never be presented as a
resolved source.

## Poland — locked Product Owner decision

For the current Phase 29 rollout, Poland is deliberately different from the
general target-period rule.

All supported Polish Mathematics grades, stages and pathways use:

- operational Edulytics period: `2026-2027`;
- official curriculum source period: `2025-2026`;
- accepted pack version: `PL-MATH-2025-2026`;
- source resolution: `PreviousOfficialFallback`.

The current rollout does not mix the new Polish 2026 transitional curriculum
into Class I or Class IV.

It also does not partially migrate later cohorts.

The same complete 2025-2026 baseline is used for:

- primary Classes I-VIII;
- general upper-secondary school;
- technical upper-secondary school.

Polish textbook acquisition must therefore search for books/materials aligned
to the 2025-2026 curriculum baseline.

If a school tells Edulytics which 2025-2026 textbook it actually uses, that
school-adopted textbook takes priority.

Otherwise Edulytics must resolve an evidence-backed widely-used publisher
textbook for that exact stage/pathway.

The 2025-2026 source must never be labelled as an official 2026-2027 Polish
curriculum.
